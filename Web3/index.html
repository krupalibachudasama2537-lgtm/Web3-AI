Arbitrum · Layer 2 Overview
Why Ethereum Needed Layer 2

The Scaling Problem

Ethereum mainnet handles ~15 transactions per second. At peak demand, gas fees can exceed $50 per transaction — unusable for everyday apps.

What Arbitrum Does

Arbitrum is an optimistic rollup: it processes transactions off-chain, assumes they're valid, and posts compressed data + fraud proofs to Ethereum L1.

Real-World Benefit

The same Ethereum smart contracts run on Arbitrum with ~$0.01 fees and 2-second confirmations. Developers deploy identical code — users pay 100× less.
