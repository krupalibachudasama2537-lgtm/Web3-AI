How it works: Click ⛏ Mine to find a nonce that makes the hash start with "00" (proof-of-work). Block 2's "Previous Hash" is locked to Block 1's output. If you edit Block 1's data after mining, its hash changes — and Block 2's Previous Hash no longer matches, breaking the chain. This is exactly how real blockchains achieve immutability.
